# Termux Universal Skill

Skill de uso pessoal do Termux para Zafiro Agent.
Com o tempo vou atualizando e corrigindo bugs dela.

## Sobre a Skill
Um guia universal e completo cobrindo do básico ao avançado no Termux (Android):
- **Conexão SSH & Segurança**
- **Comandos básicos e Shell**
- **Gerenciamento de Pacotes (`pkg`/`apt`)**
- **Desenvolvimento** (Python, Node.js, C/C++, Git, Perl, Ruby)
- **Editores** (Nano, Vim, Emacs)
- **Comandos Específicos do Termux** (`termux-api`, clipboard, SMS, câmera, localização, etc.)
- **Armazenamento & Interoperabilidade** (`~/storage`, SAF)
- **Bancos de Dados** (SQLite, MariaDB, PostgreSQL, Redis)
- **Servidores Web & Proxies** (Nginx, Apache, Caddy, Cloudflare Tunnels)
- **Ferramentas de Mídia** (FFmpeg, yt-dlp, ImageMagick, Pandoc)
- **Automação & Processos** (tmux, screen, cron, termux-job-scheduler)
- **Acesso Root** (`tsu`)
- **Virtualização** (`proot`, `proot-distro` - Debian, Ubuntu, Alpine)
